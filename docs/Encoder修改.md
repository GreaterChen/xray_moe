# Encoder方法修改：基于双层异构图的三阶段临床推理

## 一、整体架构概述

我们提出用**双层异构知识图谱 + 三阶段关系感知图注意力网络 (RGAT)** 替代原有的MoE模块，构建一个能够模拟结构化临床推理过程的编码器。

### 核心组件
1. **基础视觉编码器**：预训练ViT（保持不变）
2. **双层异构知识图谱**：显式建模解剖和疾病层次的医学知识
3. **三阶段RGAT推理**：模拟临床诊断的渐进推理流程

---

## 二、基础视觉感知 (Foundation: Visual Perception)

**保持原有设计**：利用预训练的ViT，为影像中Faster R-CNN定位出的29个解剖区域提取高质量的、上下文感知的初始特征向量。

- **输入**：29个解剖区域的ROI区域
- **输出**：29个解剖区域的初始特征向量 {h_a^(0)}_{a=1}^{29}
- **用途**：作为双层图中底层节点的初始表示

---

## 三、双层异构知识图谱构建

我们构建一个统一的、双层的异构知识图谱 G = (V, E)，包含不同层次的医学知识：

### 3.1 底层 - 解剖层 (Anatomy Level)

**节点定义**：
- **数量**：29个解剖区域节点 V_A = {v_a}_{a=1}^{29}
- **初始特征**：来自ViT的输出 h_a^(0)

**层内边 (Anatomy-Anatomy，A→A)**：
- **目标**：编码空间邻接和功能关联
- **构建方法**：
  1. **距离计算**：对每个样本，利用Faster R-CNN提供的bbox坐标，计算样本内各解剖区域之间的空间距离（如bbox中心点的欧氏距离）
  2. **统计聚合**：聚合训练集中所有样本的距离结果，得到每对解剖区域之间的平均距离矩阵
  3. **边构建**：基于K近邻（KNN）算法，为每个解剖区域连接K个最近邻的解剖区域
- **边类型**：离散（0/1），表示是否连接
- **边集**：E_AA ⊂ V_A × V_A

### 3.2 顶层 - 疾病层 (Disease Level)

**节点定义**：
- **数量**：14个疾病节点 V_D = {v_d}_{d=1}^{14}
- **初始特征**：随机初始化的可学习嵌入向量 h_d^(0) ∈ R^C

**层内边 (Disease-Disease，D→D)**：
- **目标**：编码临床共现关系
- **构建方法**：利用CheXpert数据集的疾病标签，计算每对疾病之间的Jaccard相似系数：
  ```
  Jaccard(d_i, d_j) = |患者同时患d_i和d_j| / |患者患d_i或d_j|
  ```
- **边类型**：**连续权重**（非0/1），直接使用Jaccard系数作为边权重
- **边集**：E_DD = {(v_i, v_j, w_ij) | v_i, v_j ∈ V_D, w_ij = Jaccard(d_i, d_j)}

### 3.3 层间连接 (Anatomy-Disease，A→D)

**目标**：编码从视觉证据到疾病假设的诊断知识

**构建方法**：
- 基于**Chest ImaGenome**数据集的实体关系提取方法
- 提取解剖区域与疾病之间的高频共现关联
- **技术细节**：具体提取规则和流程见Chest ImaGenome论文

**边类型**：离散（0/1），表示临床关联性

**边集**：E_AD ⊂ V_A × V_D

## 四、三阶段异构图注意力网络 (3-Stage RGAT)

我们的核心推理模块在统一的双层异构图上执行逐步深入的三阶段推理流程。**关键特性**：不同关系类型使用不同的注意力参数（异构图机制）。

### 4.1 阶段一：解剖区域上下文感知 (Anatomy Contextualization)

**目标**：让每个解剖区域充分理解其周边空间环境

**关系类型**：Anatomy → Anatomy (A→A)

**节点交互**：Anatomy节点 → Anatomy节点

**技术设计**：
- **逻辑**：源节点和目标节点是同一类型（视觉特征），处于同一特征空间，可共享同一个变换矩阵
- **所需参数**：
  1. **转移矩阵** W_A→A ∈ R^{C×C'}：将所有解剖区域节点的特征投影到新的表示空间
  2. **注意力向量** a_A→A ∈ R^{2C'}：学习如何评判两个解剖区域之间的重要性

**注意力计算**：
```
e_ij = LeakyReLU(a_A→A^T · [W_A→A h_i^(0) || W_A→A h_j^(0)])
α_ij = softmax_j(e_ij)
h_i^(1) = σ(Σ_{j∈N_i} α_ij · W_A→A h_j^(0))
```

**临床含义**：模拟医生在诊断前，全面扫描影像，理解各结构间的空间相互影响（如"左肺下叶靠近心脏"）

### 4.2 阶段二：疾病特异性表征聚合 (Disease-Specific Aggregation)

**目标**：从视觉证据中为每种疾病构建初步诊断假设

**关系类型**：Anatomy → Disease (A→D)

**节点交互**：Anatomy节点 → Disease节点

**技术设计**：
- **逻辑**：这是最关键的异构交互。源节点（Anatomy）的特征是**视觉的**，目标节点（Disease）的特征是**语义的**，处于完全不同的特征空间。需要分别投影到共享的潜在空间才能进行有意义的注意力计算。

- **所需参数**：
  1. **源节点转移矩阵** W_A_source ∈ R^{C'×C''}：变换作为信息来源的Anatomy节点特征
  2. **目标节点转移矩阵** W_D_target ∈ R^{C×C''}：变换作为信息目标的Disease节点特征
  3. **注意力向量** a_A→D ∈ R^{2C''}：学习如何评判一个解剖区域对于一个疾病的重要性

**注意力计算**：
```
e_ad = LeakyReLU(a_A→D^T · [W_A_source h_a^(1) || W_D_target h_d^(0)])
α_ad = softmax_a(e_ad)  # 对所有连接到疾病d的解剖区域a归一化
h_d^(1) = σ(Σ_{a∈N_d} α_ad · W_A_source h_a^(1))
```

**临床含义**：模拟医生根据观察到的影像学特征（如"心脏轮廓增大"），开始关联到具体的疾病实体（如"心脏肥大"）

### 4.3 阶段三：疾病间关系推理 (Disease Relational Reasoning)

**目标**：在抽象的疾病层面进行鉴别诊断，考虑疾病间的相互关系

**关系类型**：Disease → Disease (D→D)

**节点交互**：Disease节点 → Disease节点

**技术设计**：
- **逻辑**：源节点和目标节点是同一类型（语义特征），处于同一特征空间，可共享同一个变换矩阵
- **所需参数**：
  1. **转移矩阵** W_D→D ∈ R^{C''×C'''}：将所有疾病节点的特征投影到新的表示空间
  2. **注意力向量** a_D→D ∈ R^{2C'''}：学习如何评判两个疾病之间的重要性（如共现关系）

**注意力计算（带边权重）**：
```
e_ij = w_ij · LeakyReLU(a_D→D^T · [W_D→D h_i^(1) || W_D→D h_j^(1)])
α_ij = softmax_j(e_ij)
h_i^(2) = σ(Σ_{j∈V_D} α_ij · W_D→D h_j^(1))
```
其中 w_ij 是DD边的Jaccard相似系数权重

**临床含义**：模拟医生在形成初步诊断后，思考不同可能性之间的联系（如"肺炎"常伴随"胸腔积液"），从而得出最连贯、最合理的最终诊断

## 五、训练策略

### 5.1 保持两阶段训练框架

**Stage 1：对比学习的视觉-文本对齐**（保持不变）
- 目标：训练图像编码器和疾病分类器
- 损失函数：L_Stage-1 = L_IRC + λ₁·L_PSC + λ₂·L_BCE
- 可训练组件：
  - 语义感知图像块提取器（Faster R-CNN）
  - ViT图像编码器
  - 疾病分类器

**Stage 2：医疗报告生成**（修改点：MoE → RGAT）
- 目标：训练RGAT推理模块和报告生成器
- 损失函数：L_Stage-2 = L_CE
- 冻结组件：
  - 区域检测器
  - ViT主干网络
  - 疾病分类器
- 可训练组件：
  - **RGAT的所有参数**（W_A→A, W_A_source, W_D_target, W_D→D, a_A→A, a_A→D, a_D→D）
  - **疾病节点嵌入** {h_d^(0)}_{d=1}^{14}
  - 报告生成器参数

### 5.2 关键设计决策

| 组件 | 设计选择 | 理由 |
|------|---------|------|
| 疾病节点初始化 | 随机初始化 | 通过训练学习最优的语义表征 |
| 图结构 | 固定（预构建） | 基于医学知识和数据统计，训练时不变 |
| AA边 | 离散（KNN） | 捕获关键的空间邻接关系 |
| DD边 | 连续权重 | 保留精细的共现概率信息 |
| DA边 | 离散（二值） | 基于临床知识的确定性关联 |

## 六、与MoE方法的对比

| 维度 | MoE方法 | 双层图RGAT方法 |
|------|---------|----------------|
| 核心机制 | 专家混合 + 疾病路由 | 异构图推理 + 三阶段注意力 |
| 疾病建模 | 独立专家（LoRA） | 疾病节点 + 显式关系 |
| 解剖交互 | 通过MoE隐式处理 | 阶段1显式建模空间关系 |
| 疾病关系 | 独立处理 | 阶段3显式建模共现 |
| 知识融入 | 隐式学习 | 显式编码（3类边） |
| 可解释性 | 专家激活权重 | 三阶段注意力 + 图结构 |
| 临床模拟 | 疾病特异性处理 | 结构化推理流程 |

---

## 七、核心优势总结

✅ **更强的结构化推理**：三阶段模拟真实临床诊断流程（观察 → 关联 → 鉴别）  
✅ **显式知识建模**：将解剖关系、疾病共现、诊断关联编码为图结构  
✅ **异构关系处理**：为不同类型的关系学习专属的注意力机制  
✅ **疾病协同推理**：阶段3显式建模疾病间的相互影响和共现模式  
✅ **更好的可解释性**：每个阶段有明确的临床含义，注意力权重可可视化  
✅ **知识复用性**：图结构可作为先验知识应用于其他医疗任务
