# 三种对比学习方法说明

本项目实现了三种不同的对比学习方法，用于ViT预训练阶段（PRETRAIN_VIT）。可以通过配置参数 `CONTRASTIVE_LOSS_TYPE` 来选择使用哪一种。

---

## 1. 复杂区域对比学习 (`region`)

### 概念
在 **patch-sentence 层面**进行对比学习，使用复杂的正负样本定义策略。

### 正负样本定义
- **正样本**: 同一解剖区域 且 相同NLP状态（都是normal或都是abnormal）
- **负样本**: 
  - 同一解剖区域 但 不同NLP状态
  - 同样本的不同解剖区域 且 非同文本区域
  - 不同样本的不同解剖区域
- **忽略**: 
  - 对角线（自己与自己）
  - 同一样本中具有相同文本的不同区域

### 实现细节
- 方法: `compute_region_itc_loss()`
- 损失函数: 监督对比学习损失（Supervised Contrastive Loss）
- 特点: 考虑了医学文本的NLP状态和同文本区域分组，更精细化

### 配置方式
```python
# 在 local_config.py 中设置
CONTRASTIVE_LOSS_TYPE = "region"
ENABLE_REGION_ITC = True
REGION_ITC_TEMPERATURE = 0.07
REGION_ITC_WEIGHT = 1.0
ANATOMICAL_DATABASE_PATH = "/path/to/anatomical_database.pkl"
```

### 适用场景
- 需要精细的区域级别语义对齐
- 希望区分normal和abnormal状态
- 有高质量的解剖区域文本标注

---

## 2. 原生CLIP对比学习 (`clip`)

### 概念
在 **image-report 层面**进行对比学习，使用最经典的CLIP配对方式。

### 正负样本定义
- **正样本**: 配对的图像-报告（batch内对角线）
- **负样本**: batch内所有其他图像-报告对

### 实现细节
- 方法: `compute_clip_itc_loss()`
- 损失函数: 对称InfoNCE损失（image→text + text→image）
- 特点: 全局级别的图像-文本对齐，简单有效

### 配置方式
```python
# 在 local_config.py 中设置
CONTRASTIVE_LOSS_TYPE = "clip"
TEMPERATURE = 0.07
```

### 适用场景
- 需要全局图像-文本对齐
- 训练数据规模较大
- 作为baseline对比实验

---

## 3. 简化区域CLIP对比学习 (`simple_region_clip`) 【新增】

### 概念
在 **patch-sentence 层面**进行对比学习，但使用最简单的CLIP配对方式。

### 正负样本定义
- **正样本**: 配对的region-sentence（同一样本的同一解剖区域）
- **负样本**: batch内所有其他region-sentence对

### 实现细节
- 方法: `compute_simple_region_clip_loss()`
- 损失函数: 对称InfoNCE损失（region→text + text→region）
- 特点: 
  - 区域级别的对比学习
  - 不考虑NLP状态、同文本区域等复杂因素
  - 计算简单，训练稳定

### 配置方式
```python
# 在 local_config.py 中设置
CONTRASTIVE_LOSS_TYPE = "simple_region_clip"
REGION_ITC_TEMPERATURE = 0.07
REGION_ITC_WEIGHT = 1.0
ANATOMICAL_DATABASE_PATH = "/path/to/anatomical_database.pkl"
```

### 适用场景
- 需要区域级别的细粒度对齐
- 希望避免复杂的正负样本定义
- 作为region和clip之间的中间方案

---

## 对比总结

| 特性 | region | clip | simple_region_clip |
|-----|--------|------|-------------------|
| **层级** | patch-sentence | image-report | patch-sentence |
| **粒度** | 细粒度（29个区域） | 粗粒度（整图） | 细粒度（29个区域） |
| **正样本定义** | 复杂（考虑NLP状态） | 简单（配对） | 简单（配对） |
| **负样本定义** | 复杂（多种情况） | 简单（非配对） | 简单（非配对） |
| **损失函数** | 监督对比损失 | 对称InfoNCE | 对称InfoNCE |
| **计算复杂度** | 高 | 低 | 中 |
| **需要解剖数据库** | ✅ 是 | ❌ 否 | ✅ 是 |
| **训练稳定性** | 中 | 高 | 高 |

## 实验建议

### 1. 对比实验
建议对三种方法都进行实验，对比效果：

```bash
# 实验1: 原生CLIP
python train.py --config configs/local_config.py --loss-type clip

# 实验2: 简化区域CLIP
python train.py --config configs/local_config.py --loss-type simple_region_clip

# 实验3: 复杂区域对比学习
python train.py --config configs/local_config.py --loss-type region
```

### 2. 预期效果
- **clip**: 全局语义对齐好，但缺乏细粒度理解
- **simple_region_clip**: 区域级别对齐，比clip更细致
- **region**: 最精细的语义对齐，但可能需要更长训练时间

### 3. 消融研究
可以研究：
1. 粒度影响: clip vs simple_region_clip（粗粒度 vs 细粒度）
2. 复杂度影响: simple_region_clip vs region（简单配对 vs 复杂定义）

## 注意事项

1. **数据准备**: `simple_region_clip` 和 `region` 都需要解剖区域数据库（`ANATOMICAL_DATABASE_PATH`），而 `clip` 不需要

2. **Batch Size**: 对比学习效果与batch size正相关，建议：
   - clip: batch_size >= 32
   - simple_region_clip: batch_size >= 16
   - region: batch_size >= 16

3. **温度参数**: 
   - `TEMPERATURE`: 用于clip方法
   - `REGION_ITC_TEMPERATURE`: 用于region和simple_region_clip方法
   - 建议范围: 0.05 ~ 0.1

4. **训练稳定性**: 
   - 如果训练不稳定，可以尝试降低温度参数
   - 如果loss为NaN，会自动返回零损失并打印警告
